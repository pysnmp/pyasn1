1.3.0-rc.1 (2026-09-05)¶

Bug Fixes¶

  • encode a present OPTIONAL component even when it is empty (69f4b80), closes #119 #112

  • encoder must not instantiate absent DEFAULT components (2e7abff), closes #112

  • isInconsistent must report an exception, not a bare True (a16a043), closes #118

  • keep all components when an explicit-tag guess is refuted (09b9862), closes #116 pyasn1/pyasn1#59

  • keep the EOO when capturing an untagged Any (c396c79), closes #114 pyasn1/pyasn1#66

  • malformed BIT STRING must raise PyAsn1Error, not IndexError (6738bec), closes #121

  • re-resolve late-bound componentType on clone and subtype (6e62269), closes #111 pyasn1/pyasn1#124 etingof/pyasn1#19 etingof/pyasn1#20

  • reading a Choice alternative must not deselect another (6e5b40a), closes #122

  • report an ambiguous SEQUENCE schema instead of guessing a component (a389f1e), closes #120 pyasn1/pyasn1#84

  • security: bound OID arcs, tag numbers and Real conversion (0ff4c73), closes Hi#tag-number #110

Features¶

  • add univ.RelativeOID (X.680 RELATIVE-OID, universal tag 13) (9e274a0), closes #117 #110
